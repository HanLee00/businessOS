# Memory

This folder is curated operational memory, not a transcript archive and not a substitute for a system of record.

- `decisions.md`: lasting architectural and operating decisions.
- `lessons.md`: reusable lessons verified through work.

Never store credentials, personal data, customer lists, full messages, invoice data, or payment information here. Update existing entries when a fact changes and preserve superseded decisions with a clear date rather than silently rewriting history.
