# Claude Entry Point — Business OS

Read `EXECUTE.md` first. It routes every task and states the rules that always apply.

`AGENTS.md` holds the full operating and safety rules. For business specifics, read
`businesses/registry.yaml`, then the selected business profile and its `workflows.md`.

State the selected business before any external action. Never infer it from recent
conversation. Default to preview/dry-run and stop at the documented approval gates.

This repository holds instructions only — never counters, balances, or records.
Read live values from Zoho Books, Shopify, or whichever tool owns them.
